# Note 01 — Geometry

The circle is the shortest boundary that isolates a distance.

```math
x^2 + y^2 = r^2
```

The perimeter grows linearly with the radius; the area grows quadratically.
Interfaces behave the same way: they scale slower than the problems they contain.

```math
C = 2\pi r, \qquad A = \pi r^2
```

> Working principle: define the constraint first, then the freedom inside it.
